# 🎬 Movie Explorer

A modern movie discovery web app built with React that allows users to search for movies and explore detailed information such as ratings, release dates, descriptions, popularity, and more.

## ✨ Features

- 🔎 Search for movies using the TMDB API
- 🎬 Display movie posters and titles
- ⭐ Show movie ratings
- 📅 Show release dates
- 🌐 Display original language
- 👥 Display vote count
- 📈 Display movie popularity
- 📖 Read full movie descriptions in a popup
- ✨ Smooth UI animations using Motion
- 🖱️ Smooth scrolling using Lenis
- ⏳ Loading state
- ⚠️ Error handling
- 📱 Responsive design
- 🎨 Modern dark-themed UI

## 🛠️ Technologies Used

- React
- JavaScript
- Tailwind CSS
- Motion for React
- Lenis
- TMDB API
- Vite
